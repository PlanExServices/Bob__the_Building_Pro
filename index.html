Block 2 — Source and Legal

What this means: NEW_PRODUCT = original. AUTHORIZED_REBUILD = you own it or have written permission. PUBLIC_INSPIRATION = you admire public features and will rebuild independently. Most choose NEW_PRODUCT.
What this means: Only needed if you selected AUTHORIZED_REBUILD. Type exactly: "I confirm I own this product and have full rights to rebuild it." Or "I confirm I have written permission from [name]." Otherwise write N/A.

Block 3 — Platform and Distribution

What this means: WEB = browser app (recommended for most). MOBILE = native app. WEB_AND_MOBILE = both. DESKTOP = desktop program. If unsure, pick WEB.
What this means: LOCAL_ONLY = runs only on your computer. DEPLOYABLE_WEB = lives online. APP_STORES = Apple/Google stores. BOTH = local and online. Most start with DEPLOYABLE_WEB.

Block 4 — Core Features

What this means: List only must-have features for your app. Be specific and testable. Good example: "User signs up → creates a project → exports a file." Bad: "Good UX."
